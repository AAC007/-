# План внедрения синхронизации остатков 1С в ПО

## Цель

Заменить ручной импорт остатков через Excel прямой синхронизацией с 1С:УТ 10.3, сохранив проверяемость расчетов и возможность отката.

## Готовые исходные факты

- COM-подключение к 1С подтверждено через `C:\Users\dpd\Documents\Codex\1C_Diagnostics\test_1c_connect.py`.
- Если `pz-sql1.pzmc.org:1541` не разрешается, работает fallback `pz-sql1:1541`.
- Основной регистр остатков: `ТоварыНаСкладах`.
- Контрольные регистры: `ПартииТоваровНаСкладах`, `ТоварыОрганизаций`.
- НЗП деталей определяется по складам/секциям НЗП, например `44 секция НЗП (незавершенное производство)`, и по коду номенклатуры 1С без учета ведущих нулей.

## Архитектура внедрения

1. Добавить в `BlankDemandPlanner.Infrastructure` сервис `OneCStockSyncService`.
2. Вынести параметры подключения в настройки приложения:
   - сервер;
   - fallback-сервер;
   - база;
   - пользователь;
   - способ получения пароля: переменная окружения `ONEC_PASSWORD` или защищенное хранилище Windows.
3. Создать DTO `OneCStockRow`: код 1С, артикул, наименование, склад, код склада, единица, количество, дата получения.
4. Синхронизация должна создавать обычный `StockSnapshot` и `StockItem`, чтобы существующий расчет не менялся.
5. В UI добавить команду `Синхронизировать остатки из 1С` рядом с текущим импортом Excel.
6. Excel-импорт оставить как резервный канал.
7. Перед записью снимка показывать краткий итог: строк, складов, положительных остатков, дата получения.
8. Логировать начало/конец синхронизации без пароля и без полной строки подключения.

## Этапы реализации после команды пользователя

1. Добавить интерфейс `IOneCStockSyncService` и реализацию COM-чтения в Infrastructure.
2. Добавить настройки 1С в `Settings` и экран "Настройки".
3. Добавить команду синхронизации в `MainViewModel`.
4. Сохранять результат в существующие таблицы `StockSnapshots` и `StockItems`.
5. Добавить тесты:
   - сопоставление `00001799544` с IPS `1799544`;
   - сохранение снимка из DTO без Excel;
   - расчет после синхронизации дает тот же результат, что после Excel-импорта;
   - ошибка подключения не очищает предыдущий снимок.
6. Опубликовать новую версию в `publish/versions/<version>`.

## Ограничения

- Внедрение в WPF не начинать без отдельной команды пользователя.
- Не хранить пароль 1С в SQLite, `VERSION.md`, логах или исходном коде.
- Не удалять существующий Excel-импорт.
- Не выполнять запись документов 1С в рамках синхронизации остатков.
