# Чек-лист безопасного включения записи документов

1. Есть резервная копия базы или подтвержденный регламент восстановления.
2. Метаданные обследованы, реальные имена документов и регистров внесены в `config.json`.
3. Используется отдельный технический пользователь с минимальными правами.
4. Все dry-run тесты прошли без ошибок.
5. Каждый запрос содержит уникальный `external_id`.
6. Комментарий документа содержит отметку интеграционного модуля.
7. `ALLOW_DOCUMENT_WRITE=true` включается только на время контролируемого теста.
8. `ALLOW_DOCUMENT_POSTING=false` остается выключенным до отдельной приемки.
9. Первый тест записи создает непроведенный документ на минимальном наборе данных.
10. Созданный тестовый документ проверен в 1С и удален/помечен на удаление ответственным пользователем 1С.
11. Логи проверены: пароль и строка подключения с паролем не записаны.
12. После теста флаги записи возвращены в `false`.
