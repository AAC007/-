# Быстрый путь получения остатков из 1С

## Назначение

Этот протокол нужен, чтобы оперативно отвечать на вопросы вида: "сколько на остатке в секции 44 в 1С УТ".

## Проверенный рабочий путь

- Подключение: COM `V83.COMConnector`.
- Рабочий `.env`: `C:\Users\dpd\Documents\Codex\1C_Diagnostics\.env`.
- Python с pywin32: `C:\Users\dpd\Documents\Codex\1C_Diagnostics\.venv\Scripts\python.exe`.
- Основной сервер из профиля: `pz-sql1.pzmc.org:1541`.
- Быстрый fallback, если FQDN не разрешается: `pz-sql1:1541`.
- База: `UT_dev`.
- Основной регистр фактических остатков: `ТоварыНаСкладах`.
- Контрольные регистры для сверки по отдельному флагу `--control`: `ПартииТоваровНаСкладах`, `ТоварыОрганизаций`.
- Измерения: `Номенклатура`, `Склад`, `ХарактеристикаНоменклатуры`, `СерияНоменклатуры`, `Качество`, `Проект`.
- Ресурс остатка: `Количество`.

## Команда

Из корня проекта:

```powershell
.\onec_integration\start_stock_lookup_server.cmd
.\onec_integration\query_stock_server.cmd -Item "01-P002-03.002-T63.150.SS" -Warehouse "44"
```

Helper-сервер держит COM-подключение открытым на `http://127.0.0.1:8765`. Первый запуск может быть холодным, последующие запросы идут без повторного создания COM-соединения.

Cold-start fallback:

```powershell
.\onec_integration\lookup_1c_stock.cmd "01-P002-03.002-T63.150.SS" "44"
```

По умолчанию команда читает только `ТоварыНаСкладах`. Это самый короткий путь для ответа пользователю.

Для диагностической сверки:

```powershell
.\onec_integration\query_stock_server.cmd -Item "01-P002-03.002-T63.150.SS" -Warehouse "44" -Control
```

Для списка до 30 строк:

```powershell
.\onec_integration\query_stock_server.cmd -Item "11445" "УТ000012706" -Warehouse "44"
```

Не запускай отдельный COM-процесс на каждую строку. Если нужен файл, используй cold-start fallback `--items-file`, но для скорости предпочтителен helper-сервер.

Или напрямую:

```powershell
C:\Users\dpd\Documents\Codex\1C_Diagnostics\.venv\Scripts\python.exe .\onec_integration\tools\quick_stock_lookup.py "01-P002-03.002-T63.150.SS" "44"
```

Результат выводится в консоль и сохраняется в:

```text
onec_integration/reports/quick_stock_lookup.json
```

## Правила безопасности

- Команда только читает 1С и не создает документов.
- Пароль не выводится в консоль и не пишется в JSON.
- `.env` не копируется в репозиторий.
- Для ответа пользователю основным источником считать `ТоварыНаСкладах`; контрольные регистры использовать только по необходимости.
